## Session 23 (F-026 plugin non-ASCII header hardening)
- Date: 2026-04-15
- Goal: 把 `F-026` 官方 ClawRouter plugin 路线真正跑通到中文 prompt 场景，修掉 `x-clawrouter-reasoning` 导致的真实 `502`。
- Selected feature id: `F-026`
- Root cause:
  - 官方 plugin 在 x402 proxy 的非 streaming 返回里，会把 `routingDecision.reasoning` 原样写入 `x-clawrouter-reasoning` header。
  - 当 prompt 是中文时，reasoning 会包含 `翻译`、`类`、`设计`、`生成`、`推导` 等非 ASCII 字符；Node 在 `res.writeHead()` 阶段因此抛出 `Invalid character in header content ["x-clawrouter-reasoning"]`，最终返回 `502`。
- Changes made:
  - `scripts/model-routing/lib/plugin-routing.mjs`：新增 `sanitizeAsciiHttpHeaderValue()` 与 `patchClawRouterReasoningHeaderSource()`，用 TDD 固化 header 清洗与 dist patch 逻辑。
  - `scripts/model-routing/manage-clawrouter-plugin.mjs`：在解压官方 plugin tarball 后、安装依赖前，自动 patch `dist/index.js` / `dist/cli.js`，把 `x-clawrouter-reasoning` 改为 ASCII-safe 文本。
  - `scripts/tests/model-routing-plugin.test.mjs`：新增失败用例，覆盖中文 / 换行 header 清洗和 patch 产物内容，防止再次把非法正则或非法 header 写回 plugin dist。
  - `docs/runbooks/F-026-model-routing-plugin.md`：补记这个真实边界与修复策略。
- Validation:
  - `node --test scripts/tests/model-routing-plugin.test.mjs` → PASS (10/10)
  - `node --check scripts/model-routing/manage-clawrouter-plugin.mjs` → PASS
  - `node --check scripts/model-routing/lib/plugin-routing.mjs` → PASS
  - `bash -n scripts/model-routing/enable-clawrouter-plugin.sh scripts/model-routing/disable-clawrouter-plugin.sh scripts/model-routing/status-clawrouter-plugin.sh scripts/model-routing/test-clawrouter-plugin.sh scripts/model-routing/run-openclaw-plugin.sh` → PASS
  - `bash scripts/model-routing/enable-clawrouter-plugin.sh` → PASS
    - 证据：输出 `patched non-ascii debug header bug in dist/index.js, dist/cli.js`
    - `status` 证据：`pluginStatus=loaded`、`pluginActivated=true`、`primaryModel=blockrun/auto`
  - 真实 plugin gateway 验证 → PASS
    - `run-openclaw-plugin.sh gateway run ...` 日志出现：`BlockRun x402 proxy listening on port 8402`
    - 三类中文/推理请求直接打到 `http://127.0.0.1:8402/v1/chat/completions`，结果为：`SIMPLE` / `MEDIUM` / `REASONING`

    - `agent=clawrouter-probe` 返回 `provider=blockrun`、`model=auto`

  - 当前 `F-026` 已经不是“纸面 plugin 集成”，而是能在隔离 lab 里真实处理中文 prompt 的官方 plugin 路线。
  - `F-025` 仍是自定义 `URL + API Key` 的备用链路；这次没有再混用它来证明 plugin 能力。

## Session 24 (F-027 custom model-routing plugin)
- Date: 2026-04-15
- Goal: 基于官方 `ClawRouter` 路由逻辑做一份 repo-local OpenClaw custom plugin，执行层改走用户自己的 OpenAI-compatible `URL + API Key`，并给出真实双终端演示。
- Selected feature id: `F-027`
- Root cause:
  - 官方 `F-026` plugin 路线默认绑定 BlockRun wallet / x402，不满足“直接复用用户自己的 `URL + API Key`”这个目标。
  - 第一版 custom plugin 只覆盖了非流式 JSON happy path；当 OpenClaw 走 streaming chat completions 时，需要透传 `stream:true` 与 SSE，而不是重建成简化的非流式请求。
  - 同时，provider model 条目缺少 `cost` 结构，OpenClaw 在 usage 归一化阶段会崩溃。
- Changes made:
  - 新增 `specs/027-custom-model-routing-plugin/{spec,plan,tasks}.md`，冻结边界：只做模型智能路由，不扩到 Agent routing / 渠道绑定 / UI 大改。
  - 新增 `scripts/model-routing/custom-plugin/`，实现 repo-local `opensparrow-router` plugin；路由内核真实复用 `@blockrun/clawrouter` 的 `route()` / `DEFAULT_ROUTING_CONFIG`，执行层改走用户自定义 OpenAI-compatible 上游。
  - 新增 `scripts/model-routing/lib/custom-plugin-routing.mjs` 与 `scripts/tests/custom-model-routing-plugin.test.mjs`，用 TDD 固化 provider config、tier map、ASCII-safe debug header、streaming curl 参数等纯逻辑。
  - `scripts/model-routing/custom-plugin/src/index.mjs`：把上游执行层改为真实透传 streaming/non-streaming chat completions，请求体只覆写 `model`，不再丢失 `stream` / `stream_options` / tools 等字段；同时补上 provider cost 结构，避免 usage 归一化崩溃。

  - 新增 `scripts/model-routing/watch-custom-routing-plugin-log.sh`、`wait-chat-custom-routing-plugin.sh`、`open-custom-routing-demo-terminals.sh` 与 `platforms/mac/wrappers/06-模型智能路由双终端演示.command`，提供稳定双终端演示入口。
