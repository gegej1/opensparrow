## Session 11 (Research: Unified Repo Cross-Platform Risk)
- Date: 2026-03-23
- Goal: 回答“统一源码仓后，会不会因为 Mac / Windows 入口脚本不同而产生不可控因素？”
- Investigation scope:
  - Mac wrapper：`.command` + Bash
  - Windows wrapper：`.cmd` + PowerShell
  - 共享安装层：`scripts/openclaw-usb/install-local-feishu.{sh,ps1}` 与 `harden-local-feishu.{sh,ps1}`
- Confirmed findings:
  1) 统一仓库 ≠ 统一入口脚本；入口层不同本身不是阻止统一仓库的理由；
  2) 真正共享的是安装契约、配置动作、验证链，而不是 `.command` / `.cmd` 语法；
  3) 真正的风险是 wrapper 双线漂移、换行/权限差异、runtime 布局差异、host service manager 语义差异；
  4) 这些风险都属于“可控平台差异”，不属于“统一仓库不可做”。
- New deliverable:
  - `longrun/workspaces/openclaw-usb-portable/execution/docs/cross-platform-unification-risk-assessment-20260323.md`
- Recommendation:
  - 继续采用“一个统一真源仓 + 两个平台 wrapper 层 + 一个共享契约层”的方向；
  - 不追求把 Mac / Windows 入口脚本硬合并成一份脚本。
