# OpenClaw Windows Companion 使用指南

## 1. 目录定位

`platforms/windows/companion/` 中的 `.ps1` 文件是 **Windows companion source 模板**。

它们应放在一个带有 `npx.cmd`、`package.json` 与 OpenClaw runtime 依赖的根目录中运行，例如：

- `vendor/windows-openclaw/`
- 之后生成的 Windows 交付包 runtime 根目录

当前脚本已在启动时自动切换到脚本所在目录，并优先使用同目录下的 `npx.cmd`；因此复制到 runtime 根目录后，右键“使用 PowerShell 运行”即可。

## 2. 当前导入的脚本清单

| 文件 | 实际命令 | 用途 |
| --- | --- | --- |
| `onboard.ps1` | `npx openclaw onboard` | 首次初始化 |
| `start-gateway.ps1` | `npx openclaw gateway --force` | 日常启动网关 |
| `pairing.ps1` | `npx openclaw pairing approve feishu <配对码>` | 飞书配对 |
| `stop-gateway.ps1` | `npx openclaw gateway stop` | 停止网关 |
| `reset-gateway.ps1` | `npx openclaw gateway reset` | 重置网关状态 |

## 3. 推荐流程

### 首次启用

1. 右键 `onboard.ps1` → 选择“使用 PowerShell 运行”
2. 右键 `start-gateway.ps1` → 选择“使用 PowerShell 运行”
3. 如需飞书接入，先在 `pairing.ps1` 中替换 `$script:PairingCode`，再运行 `pairing.ps1`

### 日常使用

1. 右键 `start-gateway.ps1` → “使用 PowerShell 运行”

### 暂停服务

1. 右键 `stop-gateway.ps1` → “使用 PowerShell 运行”

### 重新部署 / 异常恢复

1. 运行 `stop-gateway.ps1`
2. 运行 `reset-gateway.ps1`
3. 重新运行 `onboard.ps1`
4. 重新运行 `start-gateway.ps1`
5. 如需重新绑飞书，再编辑并运行 `pairing.ps1`

## 4. 配对码修改方式

1. 右键 `pairing.ps1`，选择“编辑”
2. 找到这一行：`$script:PairingCode = "JC5RH8G6"`
3. 替换为实际配对码
4. 保存后再运行 `pairing.ps1`

## 5. 使用注意事项

- 如果脚本所在目录没有 `npx.cmd`，脚本会回退到系统 PATH 中的 `npx`。
- 若既没有本地 `npx.cmd` 也没有系统 `npx`，脚本会直接报错退出。
- 如需在仓库中验证 PowerShell 语法，可使用：

```powershell
pwsh -NoProfile -Command "[void][System.Management.Automation.Language.Parser]::ParseFile('platforms/windows/companion/start-gateway.ps1',[ref]$null,[ref]$null)"
```
