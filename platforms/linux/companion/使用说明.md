# OpenClaw Linux Companion 使用说明

## 1. 目录定位

`platforms/linux/companion/` 中的文件是 **companion source 模板**，不是仓库根目录下可直接运行的完整 runtime。

使用前请先把以下脚本复制到一个带有 `bin/` 子目录的 OpenClaw runtime 根目录中，例如：

- `vendor/linux-openclaw/`
- 之后生成的 Linux 交付包 runtime 根目录

复制完成后，再在该 runtime 根目录中执行脚本。

## 2. 当前导入的脚本清单

| 文件 | 实际命令 | 用途 |
| --- | --- | --- |
| `初始化.sh` | `npx openclaw onboard` | 首次初始化 |
| `配对.sh` | `npx openclaw pairing approve feishu` | 飞书配对 |
| `日常使用.sh` | `npx openclaw gateway --force` | 日常启动网关 |
| `关闭.sh` | `npx openclaw gateway stop` | 停止网关 |
| `重置.sh` | `npx openclaw reset` | 恢复初始状态 |

这些脚本现在会基于脚本所在目录解析 `bin/`，因此复制到 runtime 根目录后，可以从任意终端当前目录执行，例如：

```bash
bash ./初始化.sh
bash ./日常使用.sh
```

## 3. 推荐流程

### 首次启用

1. 运行 `初始化.sh`
2. 运行 `配对.sh`
3. 运行 `日常使用.sh`

### 日常使用

1. 运行 `日常使用.sh`

### 暂停服务

1. 运行 `关闭.sh`

### 重新部署 / 异常恢复

1. 运行 `关闭.sh`
2. 运行 `重置.sh`
3. 运行 `初始化.sh`
4. 运行 `配对.sh`
5. 运行 `日常使用.sh`

## 4. 执行提示

- 如果脚本报错找不到 `bin/`，说明脚本还没有放到 runtime 根目录。
- 如果脚本能进入 `bin/` 但 `npx openclaw ...` 失败，说明 runtime 依赖未准备好，需要先检查对应 runtime 包内容。
- 如需批量校验脚本语法，可在仓库根目录执行：`bash -n platforms/linux/companion/*.sh`
