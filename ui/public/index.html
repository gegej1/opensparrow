钉钉

如何获取？ ↗
在钉钉开放平台创建企业内部应用，添加机器人能力，消息接收模式选 Stream 模式
  • CorpId（企业 ID）来自开放平台应用详情页。
  • Client ID（兼容 AppKey）与发送接口中的 Robot Code 使用同一值。
  • 机器人能力已开启，消息接收方式为 Stream。
  • 事件订阅已勾选消息接收相关事件，并已保存。
  • 后台改配置后，务必发布最新应用版本再测试。

一次填写即可，系统会按同值处理 Robot Code

若不填，默认复用 Client ID；若填写则优先使用该值

企业微信

社区插件文档 ↗ 自建应用后台 ↗
今晚 packaged 首发不对外承诺企业微信 ready 状态。当前页面保留社区插件入口，供后续补证 / 兼容使用；若你自行尝试，仍以 Bot ID + Bot Secret 为主链路必填，自建应用 / callback 字段只属增强项。
  • 机器人模式选择 API + 长连接，Bot ID 通常以 aib 或 aib_ 开头。
  • 仅填写 CorpId / CorpSecret / AgentId 还不能让企微渠道变成 configured；Bot ID + Bot Secret 仍是必填。
  • 自建应用字段是增强功能：可选支持应用消息出站、回调入站和 AES 解密。
  • 如启用回调入站，需同时填写 Callback Token、EncodingAESKey、Callback Path。
