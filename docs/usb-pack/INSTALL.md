# OpenSparrow 安装指南

当前版本：`0.1.0-alpha`

这份指南面向第一次安装 OpenSparrow 的用户。
你不需要安装 Node.js、Python、Docker 或其他开发工具；交付包已经包含运行所需内容。

## 一、系统要求

- macOS 12.0 及以上
- Windows 10 及以上
- 浏览器：Chrome 90+ / Safari 14+ / Edge 90+
- 能正常访问互联网
- 不需要额外安装任何其他软件

## 二、开始前你需要准备什么

在安装前，请先准备好你要接入的平台凭据：

- 飞书：`App ID` + `App Secret`
- 钉钉：`Client ID`（或 AppKey）+ `Client Secret`（或 AppSecret）

如果你暂时还没有这些凭据，可以先跳到本文后面的“飞书凭据获取指南”或“钉钉凭据获取指南”。

## 三、Mac 安装步骤

1. 打开交付包目录。
2. 双击 `01-开始部署.command`。
3. 稍等片刻，浏览器会自动打开：`http://localhost:19000`
   - 如果你的电脑上 `19000` 端口已被占用，系统会自动切换到下一个可用端口，例如 `19001`。
4. 在安装向导中选择你要使用的渠道：
   - 飞书
   - 钉钉
5. 按页面提示填写凭据：
   - `App ID / Client ID`
   - `App Secret / Client Secret`
6. 点击“安装”并等待完成。
7. 安装成功后，页面会自动跳转到 Dashboard。
8. 在 Dashboard 中查看 Bot 状态是否为正常运行。

## 五、AI 技能包选择

安装过程中，你会看到“选择 AI 技能包”界面。

OpenSparrow 内置了超过 6 万个行业 AI 技能，覆盖 6 大领域：

| 领域 | 说明 | 技能数量 |
|------|------|---------|
| 商业 (Business) | 营销、管理、运营、创业 | ~11,000 |
| 教育 (Education) | 教学、培训、课程设计 | ~11,000 |
| 金融 (Finance) | 投资、财务、风控、审计 | ~10,600 |
| 政务 (Government) | 公文写作、政策分析、行政管理 | ~10,300 |
| 医疗 (Healthcare) | 医学知识、健康管理、临床辅助 | ~10,400 |
| 工具 (Utilities) | 通用效率提升、编程辅助、文档处理 | ~10,100 |

### 怎么选？

- 根据你的工作领域勾选一个或多个行业包
- 不确定选什么？可以先不选，以后随时重新安装
- 不勾选也完全没问题，基础 AI 技能（superpowers）会自动安装

### 安装时间

- 只装基础包：几秒钟
- 每多选一个行业包：约增加 1-2 分钟
- 全选（6 个行业包）：约 5-10 分钟
- 安装过程中请不要关闭浏览器或命令行窗口

### 安装后技能在哪里？

安装完成后，技能文件会自动部署到：

- Claude Code 用户：`~/.claude/skills/`
- Codex 用户：`~/.codex/skills/`

你不需要手动操作任何文件，一切都是自动的。

## 六、安装完成后怎么确认成功

看到以下任意几个结果，通常就表示安装成功：

- 页面自动跳转到 Dashboard
- Dashboard 中可以看到服务状态为“运行中”
- 你选择的渠道（飞书 / 钉钉）显示已启用
- 向 Bot 发送一条测试消息后，能够收到回复

## 七、常见问题

### 1. 端口 19000 被占用怎么办？

不用手动处理。
OpenSparrow 会自动尝试下一个可用端口，例如：`19001`、`19002`。

如果浏览器没有自动打开，请手动查看启动窗口中显示的地址，并复制到浏览器打开。

### 2. 安装失败怎么重试？

如果安装过程中失败：

1. 先不要关闭页面
2. 记下页面上的报错信息
3. 回到安装向导，检查填写的凭据是否正确
4. 重新点击“安装”再试一次

如果还是失败，建议：

- 重新打开安装入口
- 再次填写凭据
- 确认网络正常
- 确认渠道后台中的应用权限已经开通

### 3. 如何重置配置？

如果你想从头重新安装：

1. 打开 Dashboard
2. 找到“全量重置”或“重置配置”按钮
3. 点击后按提示确认
4. 页面会自动回到安装向导
5. 重新填写凭据并再次安装

如果已经无法进入 Dashboard，可以重新启动安装入口，再打开安装页面处理。

### 4. 如何查看日志？

如果需要把问题反馈给支持人员，请优先提供以下内容：

- 安装包目录中的 `.openclaw-usb-runtime/` 目录
- 或用户目录中的运行状态目录：
  - macOS：`~/.openclaw-usb-portable/`
  - Windows：`%USERPROFILE%\.openclaw-usb-portable\`

如果你不确定该发哪个文件，直接把整个日志目录打包发给支持人员即可。

### 5. 想更换已安装的技能包怎么办？

1. 打开浏览器访问 `http://localhost:19000/api/reset`
2. 确认重置
3. 重新安装，这次选择不同的技能包即可

### 6. 安装技能包时很慢是正常的吗？

是的。每个行业包包含约 1 万个技能文件，复制需要时间。
请耐心等待，不要中途关闭程序。

## 八、飞书凭据获取指南

### 你要找的内容

- `App ID`
- `App Secret`

### 获取步骤

1. 打开飞书开放平台。
2. 进入你的企业自建应用详情页。
3. 打开“凭证与基础信息”页面。
4. 复制：
   - `App ID`
   - `App Secret`
5. 回到 OpenSparrow 安装向导，粘贴进去。

### 截图位置提示

通常在应用详情页的中部或右侧，可以看到“凭证”“基础信息”“App ID / App Secret”等字样。
如果 `App Secret` 被隐藏，点击“显示”或“重置后复制”。

## 九、钉钉凭据获取指南

### 你要找的内容

- `Client ID`（有些页面会显示为 `AppKey`）
- `Client Secret`（有些页面会显示为 `AppSecret`）

### 获取步骤

1. 打开钉钉开放平台 / 开发者后台。
2. 进入你的应用详情页。
3. 打开“凭证与基础信息”或类似名称的页面。
4. 复制：
   - `Client ID / AppKey`
   - `Client Secret / AppSecret`
5. 回到 OpenSparrow 安装向导，粘贴进去。

### 截图位置提示

通常在应用详情页的“基础信息”“开发信息”或“凭证信息”卡片区域。
如果你看到的是 `AppKey / AppSecret`，可以直接对应填入安装向导里的 `Client ID / Client Secret`。

## 十、需要帮助时建议提供哪些信息

如果你需要技术支持，请尽量同时提供：

- 你的系统版本（macOS / Windows）
- 你使用的是飞书还是钉钉
- 页面上的报错截图
- 当前打开的本地地址（例如 `http://localhost:19000`）
- 日志目录压缩包

这样可以更快定位问题。
