## 一、安装前准备

### 1.1 系统要求

| 平台 | 最低要求 |
|------|---------|
| macOS | 12.0（Monterey）及以上 |
| Windows | Windows 10 及以上 |
| Linux | Ubuntu 20.04 / Debian 11 及以上 |
| 浏览器 | Chrome 90+ / Edge 90+ / Safari 14+ |

📌 **不需要安装任何其他软件**——Node.js、Python、Docker 均已内置在交付包中，开箱即用。

### 1.2 需要提前准备的凭据

在安装前，请根据你要接入的 IM 平台，提前准备好对应凭据：

**飞书**
- App ID（例：`cli_xxxxxxxxxx`）
- App Secret（例：`xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`）
- 获取位置：飞书开放平台 → 我的应用 → 选择应用 → 凭证与基础信息

**钉钉**
- Client ID（有些页面显示为 AppKey）
- Client Secret（有些页面显示为 AppSecret）
- 获取位置：钉钉开放平台 → 应用开发 → 选择应用 → 基础信息

**企业微信**
- Bot ID
- Bot Secret
- 可选增强项：CorpId、CorpSecret、AgentId、Reply Format
- 可选高级项：Callback Token、EncodingAESKey、Callback Path
- 获取位置：按当前企微接入方式准备；`Bot ID + Bot Secret` 为主链路必填，自建应用增强字段仍在企业微信管理后台 → 应用管理 → 选择应用 → 查看详情

**AI 模型 API Key**（任选其一）
- Anthropic Claude：https://console.anthropic.com → API Keys
- OpenAI：https://platform.openai.com → API Keys
- DeepSeek：https://platform.deepseek.com → API Keys
- 其他支持 OpenAI 格式的模型均可使用

## 二、快速安装（5 分钟）

### 2.1 解压交付包

如果收到的是 `.zip` 压缩文件，先解压到任意目录（例如桌面）。

解压后你会看到这样的目录结构：
```
opensparrow-pack/
├── 01-开始部署.command    ← macOS 入口
├── one-click-deploy.cmd   ← Windows 入口
├── run-openclaw-usb.sh    ← Linux 入口
├── docs/
├── skills/
└── ...
```

### 2.2 启动安装向导

> ⚠️ **三个平台唯一的区别就在这一步**，后续步骤完全相同。

| 平台 | 操作 |
|------|------|
| **macOS** | 双击 `01-开始部署.command` |
| **Windows** | 双击 `one-click-deploy.cmd` |
| **Linux** | 打开终端，执行 `bash run-openclaw-usb.sh` |

**macOS 安全提示处理**：如果系统弹出"无法打开，因为无法验证开发者"提示：
1. 右键点击文件 → 选择"打开"
2. 在弹出对话框中点击"打开"
3. 之后就可以正常双击运行了

**Windows SmartScreen 处理**：如果出现蓝色安全警告：
1. 点击"更多信息"
2. 点击"仍要运行"

### 2.3 打开安装页面

启动后，浏览器会自动打开安装向导：

```
http://localhost:19000
```

如果浏览器没有自动打开，请手动将上面的地址复制到浏览器地址栏。

📌 如果 19000 端口被占用，系统会自动切换到下一个可用端口（如 19001、19002），请查看启动窗口中显示的实际端口。

### 2.4 填写渠道凭据

在安装向导中：
1. 选择你要接入的平台（飞书 / 钉钉 / 企业微信，可多选）
2. 填写对应凭据（App ID + App Secret 等）
3. 填写 AI 模型 API Key

### 2.5 选择技能包（可跳过）

系统会显示"选择 AI 技能包"界面，根据你的行业选择：

| 行业包 | 说明 |
|--------|------|
| 商业 | 营销、管理、运营 |
| 教育 | 教学、培训、课程设计 |
| 金融 | 投资、财务、风控 |
| 政务 | 公文写作、政策分析 |
| 医疗 | 医学知识、临床辅助 |
| 工具 | 通用效率、编程辅助 |

📌 不确定选什么？可以先跳过，以后随时重新安装。基础技能包（superpowers）会自动安装，无需手动选择。

### 2.6 点击安装并等待

点击"安装"按钮后，等待安装完成：
- 只装基础包：约 10 秒
- 每个行业包：约 1-2 分钟
- 全选 6 个包：约 5-10 分钟

⚠️ 安装过程中**请不要关闭浏览器或命令行窗口**。

### 2.7 验证安装成功

✅ **成功标志**：
- 页面自动跳转到 Dashboard
- Dashboard 中能看到渠道状态为"已启用"
- 向 Bot 发送一条消息，Bot 有回复

## 三、API Key 配置与轮换

### 3.1 什么时候需要更换 API Key

- API Key 泄露或被他人使用
- 余额用完，需要换新 Key
- 想切换到其他模型提供商（如从 OpenAI 换到 DeepSeek）
- Key 被平台封禁或限制

### 3.2 方法一：通过 Dashboard 修改（推荐）

1. 打开浏览器，访问 `http://localhost:19000`
2. 进入 Dashboard
3. 点击"设置" → "AI 接入"
4. 找到 API Key 配置项
5. 清除旧 Key，填入新 Key
6. 点击"保存"
7. 点击"重启服务"使配置生效

### 3.3 方法二：直接编辑配置文件（高级）

配置文件位置：

| 平台 | 路径 |
|------|------|
| macOS / Linux | `~/.openclaw-usb-portable/agents/main/agent/auth-profiles.json` |
| Windows | `%USERPROFILE%\.openclaw-usb-portable\agents\main\agent\auth-profiles.json` |

文件格式示例：

```json
{
  "version": 1,
  "profiles": {
    "openai:default": {
      "type": "openai",
      "provider": "openai",
      "key": "sk-xxxxxxxxxxxxxxxxxxxxxxxx",
      "baseUrl": "https://api.openai.com/v1"
    }
  }
}
```

**字段说明：**
- `key`：填入你的新 API Key
- `baseUrl`：API 地址，如果使用中转站或国内镜像，修改此字段

📌 修改配置文件后，需要**重启服务**才能生效：重新双击启动脚本，或在 Dashboard 中点击"重启服务"。

### 3.4 支持的模型与 Base URL

| 模型提供商 | Base URL |
|-----------|---------|
| OpenAI 官方 | `https://api.openai.com/v1` |
| Anthropic Claude | `https://api.anthropic.com` |
| DeepSeek | `https://api.deepseek.com/v1` |
| 阿里云通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 国内 OpenAI 中转站 | 由服务商提供，通常格式为 `https://xxx.xxx.com/v1` |

## 四、渠道管理（飞书 / 钉钉 / 企微）

渠道是指 IM 平台的接入路线。当前 Dashboard 固定提供飞书 / 钉钉 / 企业微信三张卡片；通过每张卡片右侧的“编辑”打开配置弹窗，通过卡片上的启用开关控制启停。

### 4.1 配置渠道

1. 打开 Dashboard（`http://localhost:19000`）
2. 点击"渠道管理"
3. 在目标渠道卡片上点击"编辑"
4. 在弹窗中填写或更新对应渠道配置

**飞书渠道**需要填写：
- App ID
- App Secret

**钉钉渠道**核心字段：
- Client ID（核心；有些历史页面会显示为 AppKey）
- Client Secret（核心；有些历史页面会显示为 AppSecret）
- 可选元数据：CorpId
- 可选兼容 / 展示字段：RobotCode

**企业微信渠道**核心字段：
- Bot ID
- Bot Secret
- 可选增强项：CorpId、CorpSecret、AgentId、Reply Format
- 可选高级项：Callback Token、EncodingAESKey、Callback Path

5. 填写完成后点击"保存"
6. 如需启用该渠道，使用卡片上的启用开关；状态显示为"已启用"即配置生效

### 4.2 企业微信回调增强配置（可选）

仅当你启用了企业微信自建应用增强出站 / 回调入站时，才需要在**管理后台**配置消息接收服务器地址；如果当前只使用 `Bot ID + Bot Secret` baseline，可先跳过本节。

1. 进入企业微信管理后台 → 应用管理
2. 找到你的应用 → 接收消息 → 设置 API 接收
3. 在"URL"字段填入：`http://你的IP地址:18889/wecom/callback`
4. 填写 Token 和 EncodingAESKey（需与 OpenSparrow 中的 Callback Token / EncodingAESKey 保持一致）

📌 如果你部署在内网，外部用户访问可能需要配置内网穿透或端口转发。

### 4.3 启用 / 停用渠道

1. 在"渠道管理"列表中找到目标渠道卡片
2. 点击卡片上的启用开关
3. ✅ 状态切换为"已启用"或"已禁用"，配置会保留，后续可继续编辑

### 4.4 清空渠道配置（当前 baseline 不提供单独删除按钮）

1. 当前 Dashboard baseline 只固定提供三张渠道卡片、弹窗保存与启用开关，不提供独立的"删除渠道"按钮
2. 如需彻底清空所有渠道配置，可参考本文 `5.3 安装后追加技能包` 中的重置流程后重新配置
3. 更广的 replay / docs parity 收口留给 `F-025`

## 五、Skill 技能商场

### 5.1 技能包是什么

技能包（Skill Pack）是 AI 助手的"专业知识模块"。每个技能包是一批 Markdown 文档，告诉 AI 在特定场景下如何工作，让 AI 的回答更专业、更准确。

OpenSparrow 内置了 **69,000+ 个行业技能**，分为 6 大类别：

| 类别 | 说明 | 技能数 |
|------|------|--------|
| 🏢 商业 | 营销策划、企业管理、运营增长 | ~11,600 |
| 📚 教育 | 教学设计、培训课程、学习辅导 | ~14,400 |
| 💰 金融 | 投资分析、财务管理、风险控制 | ~11,200 |
| 🏛️ 政务 | 公文写作、政策分析、行政管理 | ~10,600 |
| 🏥 医疗 | 医学知识、健康管理、临床辅助 | ~11,200 |
| 🔧 工具 | 通用效率提升、编程辅助、文档处理 | ~10,300 |

此外，还有一个自动安装的**基础技能包（superpowers）**，包含 32 个通用智能工作技能。

### 5.2 安装时选择技能包

在安装向导的"选择 AI 技能包"步骤：
1. 根据你的行业勾选对应类别
2. 可以多选
3. 不确定就先不选，基础包会自动安装
4. 点击"继续安装"

**安装时间参考：**
- 只装基础包：< 10 秒
- 每个行业包：约 1-2 分钟
- 全选 6 个行业包：约 5-10 分钟

### 5.3 安装后追加技能包

如果安装时没选，或者想补充其他类别：

1. 打开浏览器，访问 `http://localhost:19000/api/reset`
2. 确认重置（注意：这会清除渠道配置，需要重新填写凭据）
3. 重新走安装向导，这次勾选你需要的技能包

### 5.4 技能文件存放位置

安装完成后，技能文件会自动部署到：

| 工具 | 路径 |
|------|------|
| Claude Code 用户 | `~/.claude/skills/` |
| Codex 用户 | `~/.codex/skills/` |

无需手动操作，全部自动完成。

## 六、常见问题与故障排查

### ❓ 浏览器没有自动打开

手动在浏览器地址栏输入：`http://localhost:19000`  
如果提示无法连接，查看启动窗口中实际显示的端口号（可能是 19001 等）。

### ❓ 端口 19000 被占用

不需要手动处理，系统会自动切换到下一个可用端口（19001、19002……）。

### ❓ 安装失败了怎么重试

1. 不要关闭浏览器页面
2. 记下错误信息
3. 检查填写的凭据是否正确（App ID/Secret 等）
4. 重新点击"安装"按钮再试一次

### ❓ 想从头重新安装

1. 打开 Dashboard
2. 找到"全量重置"按钮
3. 确认操作
4. 页面自动回到安装向导
5. 重新填写凭据，重新安装

### ❓ 如何查看日志

| 平台 | 日志目录 |
|------|---------|
| macOS / Linux | `~/.openclaw-usb-portable/logs/` |
| Windows | `%USERPROFILE%\.openclaw-usb-portable\logs\` |

如需反馈问题，请将日志目录打包发给技术支持。

### ❓ Bot 不回复消息

请逐项排查：
1. 检查 Dashboard 中渠道状态是否为"已启用"
2. 检查 AI 模型 API Key 是否有效（余额是否充足）
3. 检查网络是否正常（能访问外网）
4. 查看日志是否有报错信息

### ❓ macOS 说"文件已损坏"或无法验证

```bash
# 在终端执行以下命令解除隔离
xattr -cr /path/to/opensparrow-pack/
```

将 `/path/to/opensparrow-pack/` 替换为你的实际路径。
