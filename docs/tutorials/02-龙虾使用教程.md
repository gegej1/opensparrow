## 一、龙虾到底能干什么

很多人第一次用龙虾，不知道从哪里开始。其实很简单——

**把它当一个随叫随到、永远不嫌烦的超级同事。**

你可以在飞书、钉钉、企业微信里直接 @ 它，就像和同事发消息一样。它能帮你：

| 你的需求 | 龙虾能做的 |
|---------|-----------|
| 写东西 | 写邮件、写方案、写周报、写公告、写合同 |
| 看东西 | 分析数据、读合同、总结文档、提炼要点 |
| 想东西 | 出主意、对比方案、帮你做决策 |
| 翻东西 | 中英互译、改写润色、调整语气 |
| 问东西 | 医疗、法律、金融、行业知识随时问 |
| 自动化 | 定时发报告、自动总结会议、批量处理文本 |

## 二、和龙虾对话的基本方式

### 2.1 在飞书 / 钉钉 / 企微中对话

安装完成后，找到你的 Bot，直接发消息就行。支持三种模式：

**① 私聊 Bot**（最常用）
直接和 Bot 发消息，适合个人任务、隐私内容。

**② 在群里 @ Bot**
把 Bot 加入工作群，需要它时 @ 一下，团队所有人都能看到回复，适合团队协作。

```
@龙虾 帮我把这段话翻译成英文：
[粘贴你要翻译的内容]
```

**③ 连续多轮对话**
龙虾会记住当前对话的上下文，你可以不断追问、修改要求：

```
用户：帮我写一封给客户的致歉邮件
龙虾：[生成邮件]
用户：语气改得正式一些，结尾加上补偿方案
龙虾：[修改后的邮件]
```

### 2.2 发送文件和图片

可以直接把文件内容粘贴进对话，或上传图片让龙虾分析。

## 三、日常办公场景：10 个真实案例

### 📝 案例 1：5 分钟写完周报

**场景**：每周五下午要交周报，不知道怎么写。

**操作**：

```
帮我写一份本周工作周报。

本周完成的事情：
- 开了3个客户需求沟通会
- 完成了XX功能的测试
- 修复了5个线上bug

遇到的问题：
- 有一个客户需求理解不一致，已对齐

下周计划：
- 开始开发YY模块
- 准备月度复盘材料
```

**龙虾输出**：一份格式规范、语言专业的完整周报，直接可以发给领导。

---

### 📋 案例 2：会议纪要一键生成

**场景**：开完会，想快速整理出会议纪要和行动项。

**操作**：

```
下面是今天会议的简单记录，帮我整理成正式会议纪要，包含：
决议事项、行动项（负责人+截止时间）、待议事项。

[粘贴你的会议草记或录音转文字内容]
```

**龙虾输出**：
```
【会议纪要】2026-04-14

一、决议事项
1. 确定Q2营销预算为50万元
2. 新版本将于4月底上线

二、行动项
| 事项 | 负责人 | 截止日期 |
| 完成设计稿 | 小李 | 4月18日 |
| 对接第三方API | 小张 | 4月20日 |

三、待议事项
- 海外市场拓展方案（下次会议讨论）
```

## 四、Skill 技能包：给龙虾装上专业大脑

### 4.1 为什么要安装技能包？

没有技能包的龙虾，就像一个聪明但没有行业经验的应届生——什么都懂一点，但不够专业。

安装了技能包，就像给它注入了某个领域的**几年工作经验**。

### 4.2 六大行业技能包

**🏢 商业技能包**

适合：销售、运营、市场、创业者

安装后能做什么：
- 写出符合商业逻辑的营销方案
- 分析商业模式的可行性
- 生成专业的商务提案和报价单
- 用数据支撑商业决策

示例对话：
```
用户：我们要进入下沉市场，给我一个完整的市场进入策略

龙虾（安装商业技能包后）：
[输出包含市场调研方法、渠道策略、定价策略、风险评估的完整方案]
```

---

**💰 金融技能包**

适合：财务、投资、风控、CFO

安装后能做什么：
- 读懂财务报表，识别异常指标
- 分析投资项目的风险和回报
- 生成标准化的财务分析报告
- 解释复杂的金融产品条款

示例对话：
```
用户：帮我分析这份资产负债表，看看有没有流动性风险

龙虾（安装金融技能包后）：
[从流动比率、速动比率、应收账款周转等专业角度逐项分析]
```

---

**⚖️ 政务技能包**

适合：政府机关、国企、行政人员

安装后能做什么：
- 起草各类公文（通知、报告、请示、批复）
- 把口语化内容转化为正式公文格式
- 生成符合规范的汇报材料
- 政策解读和分析

示例对话：
```
用户：帮我把这个情况说明改写成正式的工作报告

龙虾（安装政务技能包后）：
[输出符合政府公文规范的格式化报告，包括标题、主送、正文、落款]
```

---

**🏥 医疗技能包**

适合：医疗机构、健康管理、医学研究

安装后能做什么：
- 解读化验报告和影像报告
- 整理病历和诊疗记录
- 解答常见医学问题
- 医学文献摘要和翻译

> ⚠️ 注意：AI 回答不能替代专业医生诊断，仅供参考。

---

**📚 教育技能包**

适合：学校、培训机构、在线教育

安装后能做什么：
- 根据学员水平设计课程大纲
- 自动出题（选择题、问答题、案例分析）
- 生成教学材料和讲义
- 设计学习评估方案

---

**🔧 工具技能包**

适合：所有需要提升效率的人

安装后能做什么：
- 更高效地处理文档和数据
- 更结构化地分析和规划
- 代码辅助（写脚本、调试错误）
- 流程设计和优化

### 4.3 如何安装技能包

安装向导中选择，或者之后通过重置重新选择：

1. 打开 `http://localhost:19000`
2. Dashboard → 技能管理 → 选择要安装的类别
3. 点击安装，等待完成（每个包约 1-2 分钟）

安装后**无需任何操作**，龙虾会自动使用对应技能包的知识回答相关问题。

## 五、让龙虾学习你的专属知识

### 5.1 上传你的文档

龙虾可以"阅读"你发给它的文档，并基于内容回答问题。

**操作方式**：直接把文档内容粘贴到对话中，然后提问。

```
下面是我们公司的《员工报销管理制度》全文，请帮我记住。
之后我会问你一些报销相关的问题。

[粘贴制度文件内容]
---
好的，现在问你：差旅费报销上限是多少？机票需要附什么材料？
```

### 5.2 建立专属知识库

如果你有大量的内部文档，可以把它们整理成 Skill（技能文件），让龙虾永久掌握。

**适用场景**：
- 公司 FAQ 和规章制度
- 行业专有知识和术语
- 产品手册和操作指南
- 自己积累的行业经验

**操作步骤**：

1. 整理你的知识内容，保存为 Markdown 文件（`.md` 格式）
2. 把文件放到技能目录：`~/.claude/skills/` （Mac/Linux）或 `%USERPROFILE%\.claude\skills\`（Windows）
3. 重启龙虾服务后，AI 会自动加载这些知识

**Skill 文件格式示例**：

```markdown
---
name: "公司报销制度"
description: "XX公司费用报销规定，2026年版"
---

# 报销制度

## 差旅费
- 交通：经济舱/高铁二等座，超出需审批
- 住宿：一线城市500元/晚，其他城市350元/晚
...
```

### 5.3 让 AI 扮演特定角色

通过在对话开始时设定角色，让龙虾更精准地服务你：

```
接下来你是我们公司的法务顾问，熟悉中国劳动法和商业合同法律。
我们公司主营业务是SaaS软件，遇到合同问题时请从保护公司利益的角度分析。

现在帮我看看这份合同有没有问题：[合同内容]
```

## 六、进阶玩法：工作流自动化

### 6.1 定时任务

龙虾支持设置定时触发的自动任务，例如：

- **每天早上 9 点**：自动推送当天日程摘要
- **每周五下午**：自动提醒团队填写周报
- **每月 1 号**：自动生成上月数据汇总报告

这需要管理员在 Dashboard 中配置，普通用户直接在 IM 中享受结果。

### 6.2 批量处理

需要处理大量重复性内容时，可以一次性提交：

```
下面有50条用户反馈，请帮我：
1. 按问题类型分类（功能问题/性能问题/体验问题/其他）
2. 统计各类型的数量和占比
3. 找出最频繁出现的 TOP 5 问题
4. 给出优化建议

[粘贴50条反馈内容]
```

### 6.3 多步骤任务链

可以把复杂任务拆解后，让龙虾逐步完成：

```
第一步：先帮我分析下面这份竞品报告的核心要点
[报告内容]

---
（等龙虾回复后继续）

第二步：基于你刚才的分析，帮我写一份给CEO的1页纸简报
要突出：对我们的威胁、我们的应对策略建议
```

## 七、对话技巧：怎么问才能得到更好的答案

### ✅ 好的提问方式

**1. 说清楚背景**
```
❌ 帮我写一封邮件
✅ 帮我写一封给重要客户的邮件，客户是国企采购部门，
   背景是我们的产品延期交付了2周，需要道歉并说明原因
```

**2. 指定输出格式**
```
✅ 用表格的形式输出
✅ 分点列出，不超过5条
✅ 写成正式商务邮件格式
✅ 用简单的话解释，我完全不懂这个领域
```

**3. 给出例子或参考**
```
✅ 仿照这个风格写：[例子]
✅ 像小红书的文案风格
✅ 参考以下模板：[模板内容]
```

**4. 分步骤进行**
```
✅ 先帮我梳理思路，再写初稿，最后我来审阅
```

### ⚠️ 使用注意事项

- **AI 可能犯错**：重要的内容（合同、数据、医学信息）请人工核实
- **保护隐私**：不要把真实的客户姓名、证件号、密码等敏感信息发给 AI
- **API Key 安全**：不要把 Key 分享给他人，也不要截图含有 Key 的页面
