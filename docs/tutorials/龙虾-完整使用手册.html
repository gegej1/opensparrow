一、安装前准备

1.1 系统要求

平台 最低要求
macOS 12.0（Monterey）及以上
Windows Windows 10 及以上
Linux Ubuntu 20.04 / Debian 11 及以上
浏览器 Chrome 90+ / Edge 90+ / Safari 14+

📌 不需要安装任何其他软件——Node.js、Python、Docker 均已内置在交付包中，开箱即用。

1.2 需要提前准备的凭据

在安装前，请根据你要接入的 IM 平台，提前准备好对应凭据：

飞书 - App ID（例：cli_xxxxxxxxxx） - App Secret（例：xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx） - 获取位置：飞书开放平台 → 我的应用 → 选择应用 → 凭证与基础信息

钉钉 - Client ID（有些页面显示为 AppKey） - Client Secret（有些页面显示为 AppSecret） - 获取位置：钉钉开放平台 → 应用开发 → 选择应用 → 基础信息

企业微信 - 企业 ID（corpid） - 应用 AgentId - 应用 Secret - 获取位置：企业微信管理后台 → 应用管理 → 选择应用 → 查看详情

AI 模型 API Key（任选其一） - Anthropic Claude：https://console.anthropic.com → API Keys - OpenAI：https://platform.openai.com → API Keys - DeepSeek：https://platform.deepseek.com → API Keys - 其他支持 OpenAI 格式的模型均可使用

二、快速安装（5 分钟）

2.1 解压交付包

如果收到的是 .zip 压缩文件，先解压到任意目录（例如桌面）。

解压后你会看到这样的目录结构：

opensparrow-pack/
├── 01-开始部署.command    ← macOS 入口
├── one-click-deploy.cmd   ← Windows 入口
├── run-openclaw-usb.sh    ← Linux 入口
├── docs/
├── skills/
└── ...

2.2 启动安装向导

⚠️ 三个平台唯一的区别就在这一步，后续步骤完全相同。

平台 操作
macOS 双击 01-开始部署.command
Windows 双击 one-click-deploy.cmd
Linux 打开终端，执行 bash run-openclaw-usb.sh

macOS 安全提示处理：如果系统弹出”无法打开，因为无法验证开发者”提示： 1. 右键点击文件 → 选择”打开” 2. 在弹出对话框中点击”打开” 3. 之后就可以正常双击运行了

Windows SmartScreen 处理：如果出现蓝色安全警告： 1. 点击”更多信息” 2. 点击”仍要运行”

2.3 打开安装页面

启动后，浏览器会自动打开安装向导：

http://localhost:19000

如果浏览器没有自动打开，请手动将上面的地址复制到浏览器地址栏。

📌 如果 19000 端口被占用，系统会自动切换到下一个可用端口（如 19001、19002），请查看启动窗口中显示的实际端口。

2.4 填写渠道凭据

在安装向导中： 1. 选择你要接入的平台（飞书 / 钉钉 / 企业微信，可多选） 2. 填写对应凭据（App ID + App Secret 等） 3. 填写 AI 模型 API Key

2.5 选择技能包（可跳过）

系统会显示”选择 AI 技能包”界面，根据你的行业选择：

行业包 说明
商业 营销、管理、运营
教育 教学、培训、课程设计
金融 投资、财务、风控
政务 公文写作、政策分析
医疗 医学知识、临床辅助
工具 通用效率、编程辅助

📌 不确定选什么？可以先跳过，以后随时重新安装。基础技能包（superpowers）会自动安装，无需手动选择。

2.6 点击安装并等待

点击”安装”按钮后，等待安装完成： - 只装基础包：约 10 秒 - 每个行业包：约 1-2 分钟 - 全选 6 个包：约 5-10 分钟

⚠️ 安装过程中请不要关闭浏览器或命令行窗口。

2.7 验证安装成功

✅ 成功标志： - 页面自动跳转到 Dashboard - Dashboard 中能看到渠道状态为”运行中” - 向 Bot 发送一条消息，Bot 有回复

三、API Key 配置与轮换

3.1 什么时候需要更换 API Key

  • API Key 泄露或被他人使用
  • 余额用完，需要换新 Key
  • 想切换到其他模型提供商（如从 OpenAI 换到 DeepSeek）
  • Key 被平台封禁或限制

3.2 方法一：通过 Dashboard 修改（推荐）

  1. 打开浏览器，访问 http://localhost:19000
  2. 进入 Dashboard
  3. 点击”设置” → “AI 接入”
  4. 找到 API Key 配置项
  5. 清除旧 Key，填入新 Key
  6. 点击”保存”
  7. 点击”重启服务”使配置生效

3.3 方法二：直接编辑配置文件（高级）

配置文件位置：

平台 路径
macOS / Linux ~/.openclaw-usb-portable/agents/main/agent/auth-profiles.json
Windows %USERPROFILE%\.openclaw-usb-portable\agents\main\agent\auth-profiles.json

文件格式示例：

{
  "version": 1,
  "profiles": {
    "openai:default": {
      "type": "openai",
      "provider": "openai",
      "key": "sk-xxxxxxxxxxxxxxxxxxxxxxxx",
      "baseUrl": "https://api.openai.com/v1"
    }
  }
}

字段说明： - key：填入你的新 API Key - baseUrl：API 地址，如果使用中转站或国内镜像，修改此字段

📌 修改配置文件后，需要重启服务才能生效：重新双击启动脚本，或在 Dashboard 中点击”重启服务”。

3.4 支持的模型与 Base URL

模型提供商 Base URL
OpenAI 官方 https://api.openai.com/v1
Anthropic Claude https://api.anthropic.com
DeepSeek https://api.deepseek.com/v1
阿里云通义千问 https://dashscope.aliyuncs.com/compatible-mode/v1
国内 OpenAI 中转站 由服务商提供，通常格式为 https://xxx.xxx.com/v1

四、渠道管理（飞书 / 钉钉 / 企微）

渠道是指 IM 平台的接入路线。你可以同时连接多个渠道，也可以随时增删。

4.1 添加新渠道

  1. 打开 Dashboard（http://localhost:19000）
  2. 点击”渠道管理”
  3. 点击”添加渠道”
  4. 选择平台类型

飞书渠道需要填写： - App ID - App Secret

钉钉渠道需要填写： - Client ID（或 AppKey） - Client Secret（或 AppSecret）

企业微信渠道需要填写： - 企业 ID（corpid） - 应用 AgentId - 应用 Secret

  1. 填写完成后点击”保存并启用”
  2. ✅ 状态变为”运行中”即添加成功

4.2 企业微信特别配置

企业微信需要在管理后台配置消息接收服务器地址：

  1. 进入企业微信管理后台 → 应用管理
  2. 找到你的应用 → 接收消息 → 设置 API 接收
  3. 在”URL”字段填入：http://你的IP地址:18889/wecom/callback
  4. 填写 Token 和 EncodingAESKey（与 OpenSparrow 中的配置保持一致）

📌 如果你部署在内网，外部用户访问可能需要配置内网穿透或端口转发。

4.3 禁用渠道（暂时停用）

  1. 在”渠道管理”列表中找到目标渠道
  2. 点击”禁用”
  3. ✅ 渠道暂停接收消息，配置保留，随时可重新启用

4.4 删除渠道（彻底移除）

  1. 在”渠道管理”列表中找到目标渠道
  2. 点击”删除”
  3. 在弹出确认框中确认操作
  4. ✅ 渠道及其配置被彻底删除，Bot 不再响应该平台消息

五、Skill 技能商场

5.1 技能包是什么

技能包（Skill Pack）是 AI 助手的”专业知识模块”。每个技能包是一批 Markdown 文档，告诉 AI 在特定场景下如何工作，让 AI 的回答更专业、更准确。

OpenSparrow 内置了 69,000+ 个行业技能，分为 6 大类别：

类别 说明 技能数
🏢 商业 营销策划、企业管理、运营增长 ~11,600
📚 教育 教学设计、培训课程、学习辅导 ~14,400
💰 金融 投资分析、财务管理、风险控制 ~11,200
🏛️ 政务 公文写作、政策分析、行政管理 ~10,600
🏥 医疗 医学知识、健康管理、临床辅助 ~11,200
🔧 工具 通用效率提升、编程辅助、文档处理 ~10,300

此外，还有一个自动安装的基础技能包（superpowers），包含 32 个通用智能工作技能。

5.2 安装时选择技能包

在安装向导的”选择 AI 技能包”步骤： 1. 根据你的行业勾选对应类别 2. 可以多选 3. 不确定就先不选，基础包会自动安装 4. 点击”继续安装”

安装时间参考： - 只装基础包：< 10 秒 - 每个行业包：约 1-2 分钟 - 全选 6 个行业包：约 5-10 分钟

5.3 安装后追加技能包

如果安装时没选，或者想补充其他类别：

  1. 打开浏览器，访问 http://localhost:19000/api/reset
  2. 确认重置（注意：这会清除渠道配置，需要重新填写凭据）
  3. 重新走安装向导，这次勾选你需要的技能包

5.4 技能文件存放位置

安装完成后，技能文件会自动部署到：

工具 路径
Claude Code 用户 ~/.claude/skills/
Codex 用户 ~/.codex/skills/

无需手动操作，全部自动完成。

六、常见问题与故障排查

❓ 浏览器没有自动打开

手动在浏览器地址栏输入：http://localhost:19000
如果提示无法连接，查看启动窗口中实际显示的端口号（可能是 19001 等）。

❓ 端口 19000 被占用

不需要手动处理，系统会自动切换到下一个可用端口（19001、19002……）。

❓ 安装失败了怎么重试

  1. 不要关闭浏览器页面
  2. 记下错误信息
  3. 检查填写的凭据是否正确（App ID/Secret 等）
  4. 重新点击”安装”按钮再试一次

❓ 想从头重新安装

  1. 打开 Dashboard
  2. 找到”全量重置”按钮
  3. 确认操作
  4. 页面自动回到安装向导
  5. 重新填写凭据，重新安装

❓ 如何查看日志

平台 日志目录
macOS / Linux ~/.openclaw-usb-portable/logs/
Windows %USERPROFILE%\.openclaw-usb-portable\logs\

如需反馈问题，请将日志目录打包发给技术支持。

❓ Bot 不回复消息

请逐项排查： 1. 检查 Dashboard 中渠道状态是否为”运行中” 2. 检查 AI 模型 API Key 是否有效（余额是否充足） 3. 检查网络是否正常（能访问外网） 4. 查看日志是否有报错信息

❓ macOS 说”文件已损坏”或无法验证

# 在终端执行以下命令解除隔离
xattr -cr /path/to/opensparrow-pack/

将 /path/to/opensparrow-pack/ 替换为你的实际路径。

四、Skill 技能包：给龙虾装上专业大脑

4.1 为什么要安装技能包？

没有技能包的龙虾，就像一个聪明但没有行业经验的应届生——什么都懂一点，但不够专业。

安装了技能包，就像给它注入了某个领域的几年工作经验。

4.2 六大行业技能包

🏢 商业技能包

适合：销售、运营、市场、创业者

安装后能做什么： - 写出符合商业逻辑的营销方案 - 分析商业模式的可行性 - 生成专业的商务提案和报价单 - 用数据支撑商业决策

示例对话：

用户：我们要进入下沉市场，给我一个完整的市场进入策略

龙虾（安装商业技能包后）：
[输出包含市场调研方法、渠道策略、定价策略、风险评估的完整方案]

💰 金融技能包

适合：财务、投资、风控、CFO

安装后能做什么： - 读懂财务报表，识别异常指标 - 分析投资项目的风险和回报 - 生成标准化的财务分析报告 - 解释复杂的金融产品条款

示例对话：

用户：帮我分析这份资产负债表，看看有没有流动性风险

龙虾（安装金融技能包后）：
[从流动比率、速动比率、应收账款周转等专业角度逐项分析]

⚖️ 政务技能包

适合：政府机关、国企、行政人员

安装后能做什么： - 起草各类公文（通知、报告、请示、批复） - 把口语化内容转化为正式公文格式 - 生成符合规范的汇报材料 - 政策解读和分析

示例对话：

用户：帮我把这个情况说明改写成正式的工作报告

龙虾（安装政务技能包后）：
[输出符合政府公文规范的格式化报告，包括标题、主送、正文、落款]

🏥 医疗技能包

适合：医疗机构、健康管理、医学研究

安装后能做什么： - 解读化验报告和影像报告 - 整理病历和诊疗记录 - 解答常见医学问题 - 医学文献摘要和翻译

⚠️ 注意：AI 回答不能替代专业医生诊断，仅供参考。

📚 教育技能包

适合：学校、培训机构、在线教育

安装后能做什么： - 根据学员水平设计课程大纲 - 自动出题（选择题、问答题、案例分析） - 生成教学材料和讲义 - 设计学习评估方案

🔧 工具技能包

适合：所有需要提升效率的人

安装后能做什么： - 更高效地处理文档和数据 - 更结构化地分析和规划 - 代码辅助（写脚本、调试错误） - 流程设计和优化

4.3 如何安装技能包

安装向导中选择，或者之后通过重置重新选择：

  1. 打开 http://localhost:19000
  2. Dashboard → 技能管理 → 选择要安装的类别
  3. 点击安装，等待完成（每个包约 1-2 分钟）

安装后无需任何操作，龙虾会自动使用对应技能包的知识回答相关问题。

五、让龙虾学习你的专属知识

5.1 上传你的文档

龙虾可以”阅读”你发给它的文档，并基于内容回答问题。

操作方式：直接把文档内容粘贴到对话中，然后提问。

下面是我们公司的《员工报销管理制度》全文，请帮我记住。
之后我会问你一些报销相关的问题。

[粘贴制度文件内容]
---
好的，现在问你：差旅费报销上限是多少？机票需要附什么材料？

5.2 建立专属知识库

如果你有大量的内部文档，可以把它们整理成 Skill（技能文件），让龙虾永久掌握。

适用场景： - 公司 FAQ 和规章制度 - 行业专有知识和术语 - 产品手册和操作指南 - 自己积累的行业经验

操作步骤：

  1. 整理你的知识内容，保存为 Markdown 文件（.md 格式）
  2. 把文件放到技能目录：~/.claude/skills/ （Mac/Linux）或 %USERPROFILE%\.claude\skills\（Windows）
  3. 重启龙虾服务后，AI 会自动加载这些知识

Skill 文件格式示例：

---
name: "公司报销制度"
description: "XX公司费用报销规定，2026年版"
---

# 报销制度

## 差旅费
- 交通：经济舱/高铁二等座，超出需审批
- 住宿：一线城市500元/晚，其他城市350元/晚
...

5.3 让 AI 扮演特定角色

通过在对话开始时设定角色，让龙虾更精准地服务你：

接下来你是我们公司的法务顾问，熟悉中国劳动法和商业合同法律。
我们公司主营业务是SaaS软件，遇到合同问题时请从保护公司利益的角度分析。

现在帮我看看这份合同有没有问题：[合同内容]

六、进阶玩法：工作流自动化

6.1 定时任务

龙虾支持设置定时触发的自动任务，例如：

  • 每天早上 9 点：自动推送当天日程摘要
  • 每周五下午：自动提醒团队填写周报
  • 每月 1 号：自动生成上月数据汇总报告

这需要管理员在 Dashboard 中配置，普通用户直接在 IM 中享受结果。

6.2 批量处理

需要处理大量重复性内容时，可以一次性提交：

下面有50条用户反馈，请帮我：
1. 按问题类型分类（功能问题/性能问题/体验问题/其他）
2. 统计各类型的数量和占比
3. 找出最频繁出现的 TOP 5 问题
4. 给出优化建议

[粘贴50条反馈内容]

6.3 多步骤任务链

可以把复杂任务拆解后，让龙虾逐步完成：

第一步：先帮我分析下面这份竞品报告的核心要点
[报告内容]

---
（等龙虾回复后继续）

第二步：基于你刚才的分析，帮我写一份给CEO的1页纸简报
要突出：对我们的威胁、我们的应对策略建议

七、对话技巧：怎么问才能得到更好的答案

✅ 好的提问方式

1. 说清楚背景

❌ 帮我写一封邮件
✅ 帮我写一封给重要客户的邮件，客户是国企采购部门，
   背景是我们的产品延期交付了2周，需要道歉并说明原因

2. 指定输出格式

✅ 用表格的形式输出
✅ 分点列出，不超过5条
✅ 写成正式商务邮件格式
✅ 用简单的话解释，我完全不懂这个领域

3. 给出例子或参考

✅ 仿照这个风格写：[例子]
✅ 像小红书的文案风格
✅ 参考以下模板：[模板内容]

4. 分步骤进行

✅ 先帮我梳理思路，再写初稿，最后我来审阅

⚠️ 使用注意事项

  • AI 可能犯错：重要的内容（合同、数据、医学信息）请人工核实
  • 保护隐私：不要把真实的客户姓名、证件号、密码等敏感信息发给 AI
  • API Key 安全：不要把 Key 分享给他人，也不要截图含有 Key 的页面
