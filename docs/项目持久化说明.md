## 后续开发建议顺序

1. 先运行 `./longrun/scripts/session_start.sh longrun/workspaces/opensparrow-unified`
2. 读取 `docs/governance/README.md` 与 `docs/governance/framework-stack.md`，再读取 `opensparrow-unified` 的 `app_spec.md`、`feature_list.json`、`claude-progress.txt`
3. 如是新需求，先用 Spec-Kit 建文档：
   - `./.specify/scripts/bash/create-new-feature.sh "一句话需求" --short-name xxx`
   - `./.specify/scripts/bash/setup-plan.sh`
4. 在 Codex 中继续实现，并在完成后更新 `opensparrow-unified` 的 `feature_list.json` 与 `claude-progress.txt`
