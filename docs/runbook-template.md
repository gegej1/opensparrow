# Runbook 标题

## 元数据
- 日期：`YYYY-MM-DD`
- 作者/Agent：`Codex-B`
- 关联 spec：`specs/<feature>/spec.md`

## 概述
- 用 1-2 句说明本文用途、适用范围与预期结果。

## 前置条件
- 列出执行前必须满足的环境、目录、依赖、账号、输入参数与边界条件。
- 如果本文是说明类文档而非执行型 runbook，也要说明“适合在什么阶段阅读/使用”。

## 操作步骤
1. 步骤名称

   ```bash
   # 放可直接执行的命令；如果没有固定命令，可写：# 无固定命令，按下列清单执行
   ```

   - 补充说明：写清楚该步骤要做什么、输入什么、输出什么。

2. 步骤名称

   ```bash
   # command
   ```

   - 补充说明。

## 验证方法
- 写清楚“如何确认成功”，优先给命令、返回值、文件路径、页面状态或目录结构。
- 如需人工核验，写清观察点，不要只写“确认正常”。

## 故障排查
- 常见失败场景 1：现象 → 排查命令/日志路径 → 修复动作。
- 常见失败场景 2：现象 → 排查命令/日志路径 → 修复动作。
